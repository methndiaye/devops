Description:
Task Manager — Projet Pratique DevOps
 Présentation du projet
Ce projet est une application web simple de gestion de tâches développée dans le cadre des travaux pratiques DevOps.
L’application permet aux utilisateurs :
• d’ajouter des tâches
• d’afficher les tâches
• de supprimer des tâches
L’objectif principal de ce projet n’est pas la complexité fonctionnelle de l’application, mais la mise en place d’une 
chaîne DevOps complète autour d’un projet réel.
 Architecture du projet
L’application est composée de :
Frontend: Une interface web simple développée avec : HTML, CSS et JavaScript
Backend: Une API REST développée avec : Node.js et Express.js
Base de données: La persistance des données est assurée par : SQLite
